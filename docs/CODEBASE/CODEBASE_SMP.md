# lnxrm 代码库组织与子系统说明（8：SMP 与 ACPI）

> 配套文件：`CODEBASE_OVERVIEW.md`（§1 总览）、`CODEBASE_BOOT.md`（§2 启动）、`CODEBASE_MEMORY.md`（§3 内存）、`CODEBASE_PROC.md`（§4 进程·调度·信号）、`CODEBASE_SYSCALL.md`（§5 系统调用与 ABI）、`CODEBASE_FS.md`（§6 文件系统）、`CODEBASE_DRIVERS.md`（§7 驱动）、`CODEBASE_SELFTEST.md`（§9 自测）、`CODEBASE_INVARIANTS.md`（§10 关键不变式）。构建与运行见 `../BUILD/BUILD.md`，差距与计划见 `../GAP_ANALYSIS.md`，项目概览见 `../README.md`。本文为 §8 SMP 与 ACPI。

- **ACPI**：RSDP→RSDT/XSDT→MADT，产 `acpi_collect_ap_ids()`；**表读取必须经 `ACPI_SCRATCH_VA` 弹跳窗**（`PD_HI[108]`，真机表常在恒等窗外）；`acpi_init` 在 `vmm_init` 后、`cpu_init` 前。
- **AP 拉起**（`smp.c`+`trampoline.S`）：trampoline 拷 `0x8000`、共享块 `0x9000`（**`ap_main` 传虚拟地址**）→ INIT+SIPI×3 → 轮询 ready 100 ms 超时。`ap_main` 顺序硬：`apic_enable` 最先（x2APIC 访 MMIO 会 #GP）→ GDT → GS → IDT → `cpu_protect_init` → idle → **`trampoline_signal_ready()` 必须先于一切控制台输出**（慢控制台吃光预算会被恢复 INIT 复位）→ LAPIC timer → online。
- **APIC**：xAPIC(MMIO)/x2APIC(MSR) 双路，每核各定型；只用于 INIT/SIPI/IPI（`0xF0` reschedule、`0xF2` stop）。
- **时钟与锁**：`HZ 100`，PIT 只供 LAPIC 标定；BSP LAPIC tick → `jiffies`/`sched_tick`/`fb_tick_flush`。锁表：`runq_lock`（全队列）、`task_table_lock`/`pid_lock`、`pmm_lock`/`kheap_lock`、`cache_lock`（**只做元数据、不跨 I/O**，C7，tick 门 trylock）、`blkdev->io_lock`（**每设备一把**，C10，持有期间排空该设备 FIFO、分区嵌套「分区 → 父盘」）、`fat_fs_lock`（FAT 的全局 FS 锁，与 `cache_lock` 嵌套；**不接管中断状态**，C7——取用点本就 IF=0，仍跨 I/O）、`ext2_fs_lock`（ext2 的同款全局 FS 锁，S2 起挂根所以是实际热点，同样 `spin_lock_irqon` + 跨 I/O）、`print_lock`（含 present 拷贝）、`fb_box_lock`（脏箱快照）。两把 FS 锁都是双核 FS 性能瓶颈（根是 ext2，瓶颈在 `ext2_fs_lock`）。
- **中断**：统一 `intr_frame`；`isr_common` 三段分流——IPI→`apic_eoi`、`<32` 异常（ring-3 转信号，ring-0 panic）、`≥32` **先 `apic_eoi` 再调 handler**（handler 可能切走）；IDT 49–255 全指 catch-all（IPI 必须显式覆盖）；#PF 用 `rflags.AC` 区分 WP 与 SMAP。向量：32 timer、33 键盘、36 COM1。保护位 `EFER.NXE`/`CR0.WP`/`CR4.SMEP`/`CR4.SMAP`，以及 **SYSCALL 门**（`EFER.SCE`、`STAR[47:32]=KCODE` + `STAR[63:48]=0x1B`（S3.3，SYSRET 用户 CS/SS 基数）、`LSTAR=entry_SYSCALL_64`、`SYSCALL_MASK`），由 BSP/AP 共同走 `cpu_protect_init()`，**内核镜像 W^X** 由 `vmm_kernel_wx()` 保证。
- **系统调用入口（S3.2）/ 出口（S3.3）**：`entry_SYSCALL_64`（`arch/entry64.S`）与 `isr128` 各是一道门，**压出的 `intr_frame` 逐字段同构**——SYSCALL 不压栈，所以 stub 自己合成出口尾巴（rip=rcx、rflags=r11、cs/ss 带 RPL=3）、从 `cpu_info.entry_stack_top` 载栈（与 `tss_set_rsp0()` 写的 `TSS.rsp0` 同值同函数维护）、把用户 RSP 存进 `cpu_info.entry_scratch`（Linux 存 `TSS.sp2`），偏移由 `percpu.c` 的 `_Static_assert` 钉死。**出口（S3.3 起）走 `sysretq`**：POPALL 之前先用 `sar rax,47` 守卫 `f->rip` 的规范性（SYSRET 跳非规范地址会 #GP，守卫不通过就退回 `iretq`；cs/usss 不查——`sys_sigreturn` 的帧内核自存、用户不可伪造）；规范路径 `POPALL → add rsp,16 → mov rcx,[rsp] / mov r11,[rsp+16] / mov rsp,[rsp+24] → sysretq`（**sysretq 不恢复 RSP**，用户栈指针要显式装载，同 Linux 的 `popq %rsp`）。`isr128`（`int 0x80` 门）**仍走 `iretq`**（S3.2 决策 A）。配套 GDT 重排（Option A，Linux 同形）：`e[3]=UCODE32 占位`、`e[4]=UDATA`（SS 0x23 不变）、`e[5]=UCODE`（CS 0x1B→**0x2B**）、`e[6,7]=TSS 0x30`，`tss_load(0x30)`。
- **swapgs 与 TLS（S3.4 起）**：**门槛是「GS 在 ring-3 到达时是用户的，在 ring 0 执行时必须是内核的」**，所以 `entry_SYSCALL_64` 与每个 ISR 桩（`ISR_NOERR`/`ISR_ERR`、`isr128`、`isr240-242`）进栈即 `SWAPGS_IN`（由帧里的 `cs & 3` 判：来自 ring 3 才换，来自 ring 0 不换），出口在 `POPALL` 之后、`iretq`/`sysretq` 之前再 `SWAPGS_OUT` 还回 ring-3 的 GS——没有这个配对，中断/系统调用在 ring-3 到达时 `this_cpu_data()`（`rdmsr(IA32_GS_BASE)`）就会读成用户地址，立即崩或被提权。**TLS 段选 FS**：x86-64 System V 的 `__thread` 降到 `%fs:`，`arch_prctl(56)` 的 `ARCH_SET_FS/ARCH_GET_FS` 直接写/读 `IA32_FS_BASE`；`ARCH_SET_GS/ARCH_GET_GS` 写/读 `IA32_KERNEL_GS_BASE`（swapgs 的影子段，不是正在使用的 `IA32_GS_BASE`），两段都被每任务私有字段 `task.user_fs`/`task.user_gs` 缓存，`switch_to()` 进栈前存旧/装新。四种操作各自地址门限到 `USER_MAX_VMA`（拒内核/非规范），未知码回 `EINVAL`。`fork` 把两段一起拷给子、`execve` 两段都清 0（新镜像不该继承旧镜像的线程指针），`glue_first` 首次进 ring 3 时把该任务的 GS 安上。
